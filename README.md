# MonoFocus

MonoFocus — локальный планер задач и событий. Приложение работает без сервера, сохраняет данные в браузере и остаётся доступным офлайн как PWA.

## Возможности

- Полная русская локализация с переключением на английский язык в настройках.
- «Сегодня» с быстрым добавлением, фокус-таймером, переносом на завтра и историей выполненного за день.
- Планы недели и месяца с общей сущностью задачи, drag-and-drop и командой переноса.
- Несколько заметок для каждого дня и недели, видимых в соответствующих планах и календаре.
- Автоматически чередующиеся рабочие смены, исключения и подсветка длинных выходных при переходе с первой смены на вторую.
- «События» с ближайшими, дальними и прошедшими событиями, а также месячным календарём занятости.
- «Я хочу» для идей и желаний с редактируемыми датами создания и реализации.
- Экспериментальные «Большие цели» с контекстом, следующим шагом и хронологией прогресса.
- История выполненных задач и локализованные TXT-отчёты с отдельными разделами задач, желаний и больших целей.
- JSON backup/import с безопасной миграцией старых локальных данных.
- Опциональный Rewards Lab с грейдами задач, честным случайным вознаграждением и пользовательским банком наград.

## Локальный запуск

Требуется актуальная LTS-версия Node.js.

```bash
npm install
npm run dev
```

Vite использует порт `3000` из `vite.config.ts`. Если порт занят, можно запустить проект на другом порту:

```bash
npm run dev -- --port 4307
```

## Проверки

```bash
npm run check
npm run build
```

`npm run check` последовательно запускает TypeScript, ESLint и Vitest.

## Данные и публикация

- Основные данные хранятся в `localStorage` под ключом `monofocus_v1`; JSON backup включает задачи, события, желания, заметки и большие цели.
- Rewards Lab выключен по умолчанию и хранится отдельно в `monofocus:rewards-lab:v1`; его данные намеренно не входят в backup/import планера.
- Если экспериментальная часть мешает запуску, откройте приложение с параметром `?safe=1`: планер запустится без загрузки Rewards Lab, после чего модуль можно отключить или удалить в Settings.
- Перед переносом браузера или устройства рекомендуется создать JSON backup в Settings.
- Push в `main` запускает проверку, production-сборку и публикацию GitHub Pages через GitHub Actions.

История пользовательских изменений находится в [CHANGELOG.md](CHANGELOG.md), инструкция по публикации — в [DEPLOY.md](DEPLOY.md).
