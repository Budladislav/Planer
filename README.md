# Takt

Takt — локальный планер задач и событий. Приложение работает без сервера, сохраняет данные в браузере и остаётся доступным офлайн как PWA.

## Возможности

- Полная русская локализация с переключением на английский язык в настройках.
- «Сегодня» с быстрым добавлением в начало или конец списка, переносом в текущей неделе, выполнением задним числом и историей выполненного за день.
- Планы года, месяца и недели с общей сущностью задачи, drag-and-drop и командой переноса.
- Именованные недельные шаблоны в настройках для ручного заполнения выбранной текущей или будущей недели повторяющимися каркасами без дублей.
- Несколько заметок для каждого года, месяца, недели и дня в соответствующих планах; заметки дня также отмечаются в календаре.
- Автоматически чередующиеся рабочие смены, исключения и подсветка длинных выходных при переходе с первой смены на вторую.
- «События» с ближайшими, дальними и прошедшими событиями, а также месячным календарём занятости.
- «Я хочу» для идей и желаний с необязательной датой начала, датой реализации и длительностью только при известной точке отсчёта.
- «Большие цели» с необязательной датой начала, контекстом, следующим шагом, хронологией прогресса и связанными задачами любого горизонта.
- История выполненных задач и локализованные TXT-отчёты с отдельными разделами задач, желаний и больших целей.
- Адаптивный центр управления: семь тематических разделов Settings, вложенная мобильная навигация и двухколоночная компоновка на десктопе.
- Версионированный JSON backup/import всего Takt с безопасной миграцией прежних копий только планировщика.
- Опциональные «Награды» с грейдами задач, кредитами, пятью видами ключей, редактируемым каталогом и отдельным списком необязательных покупок; для нового пользователя модуль выключен и пуст.

## Локальный запуск

Требуется актуальная LTS-версия Node.js.

```bash
npm install
npm run dev
```

Vite использует порт `3000` из `vite.config.ts`. Если порт занят, можно запустить проект на другом порту:

```bash
npm run dev -- --port 4307
```

## Проверки

```bash
npm run check
npm run build
```

`npm run check` последовательно запускает TypeScript, ESLint и Vitest.

## Данные и публикация

- Основные данные хранятся в `localStorage` под стабильным legacy-ключом `monofocus_v1`; после переименования он намеренно не меняется, чтобы установленная PWA продолжила видеть накопленные задачи.
- Официальные Награды выключены по умолчанию и хранятся отдельно. Версионированная резервная копия Takt включает планировщик, Награды и безопасный отключённый архив прежней Rewards Lab; старые planner-only копии остаются совместимыми.
- Если модуль Наград мешает запуску, откройте приложение с параметром `?safe=1`: планировщик запустится без его загрузки, после чего Награды можно отключить, сбросить или удалить в Settings.
- Перед переносом браузера или устройства рекомендуется создать JSON backup в Settings.
- Push в `main` запускает проверку, production-сборку и публикацию GitHub Pages через GitHub Actions.
- PWA-иконки используют стабильные ревизии имён ресурсов: ревизия меняется только при обновлении самого знака, чтобы Android/Chrome корректно подхватывал новый WebAPK и не скачивал те же иконки на каждом релизе.

История пользовательских изменений находится в [CHANGELOG.md](CHANGELOG.md), согласованное направление развития — в [ROADMAP.md](ROADMAP.md), инструкция по публикации — в [DEPLOY.md](DEPLOY.md).
